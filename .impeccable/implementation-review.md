# COEER 毛玻璃前端实施与验收记录

版本：coeer-glass-v1 · 日期：2026-10-24。已完成前端接入，未执行部署。

## 视觉回归修正：用户反馈后

用户实际查看的 localhost:3000 游客首页确实接近平面界面。现场检查确认浏览器支持 backdrop-filter，未启用减少透明/高对比降级，样式中的 blur(16px) 已生效；问题是页头在滚动后位于视口上方，且暗色背景近乎均匀、填充过厚。首轮验收检查了属性与交互，未充分验证肉眼可感知的材质，这是实施与验收遗漏。

修正包括固定视口的单层环境渐变、Chrome 填充 .68/.72（触屏 .84/.88）、Floating 填充 .84/.86（触屏 .92/.94）、专用的导航文字/边界/焦点颜色，以及 64px sticky 游客页头。正文卡片继续实底。

已在真实游客首页检查深浅主题、桌面和 390px 触屏尺寸及滚动后状态；新增 4 个滚动可见性/对比度场景，并将模糊层检查改为实际与视口相交且必须存在，避免“样式存在但区域已不在屏幕里”仍通过。修正后 UI 回归共 91 项通过，类型检查和构建通过；未执行部署。

## 实施范围

- P1：新增 src/app/styles/tokens.css，沿用 HSL 三元组与 Tailwind 语义映射；颜色、尺寸、圆角、主题、透明度和渐变与 design.json 同步。
- P2：侧栏、顶栏、游客页头使用 Chrome；Modal、抽屉、命令菜单与 Toast 使用 Floating。打开模态后关闭后方 Chrome 的 blur，Toast 移入活动 dialog 的实底区域。统一嵌套安全的滚动锁和焦点返回，抽屉与搜索互斥。
- P3：Card、字段、状态标签、编辑器、长文和表格实底。控件边界、禁用态、12px 元信息、16px 长文、44px 触达及移动字段统一；Toast 至少 5 秒，悬停/焦点暂停，错误保留到关闭。缓存相同 Markdown 的渲染与日期格式器，保持原有时钟刷新节奏、日期输出及数据行为。
- P4：首页/内容/成长模块通过公共组件继承材质；清理群组、管理、宿舍等局部语义色与字段样式。个人中心、空间目录、时段、预约详情使用实底与容器分栏；手机日期按钮可换行，长辅助栏取消 sticky。保留全宽工作区和所有原有业务能力。
- P5：增加隔离 UI fixture 与浏览器回归，验证真实前端组件，不连接后端写入。正常、有 blur、无支持、实底钩子、高对比、强制颜色、减少动态效果与深色主题打印颜色均有覆盖。

服务端与 shared contracts 无改动。另核对 29 份修改的路由文件，事件处理、loader、beforeLoad、校验和路由 ID 与原版本一致。没有改变预约提交、幂等、后台任务、同步/轮询、权限或接口。

## 性能对照

使用同一份真实前端与隔离数据的 Vite 优化构建，等待网络空闲与字体就绪，预热 30 帧，再对每种条件采集 179 个滚动帧间隔。对照是当前 DOM 的实底模式，不是历史版本完整应用，也不包含真实后端网络成本。桌面 1440px、手机尺寸 390px，深浅主题分别比较；这是桌面机器上的浏览器模拟，不能替代实体移动设备。

| 增强场景 | 滚动帧间隔 p95 | 相比实底 | >50ms 长任务 | 可见 blur 区域 |
| --- | --- | --- | --- | --- |
| 1440px / light | 6.40ms | -3.03% | 0 | 2 |
| 1440px / dark | 6.40ms | -3.03% | 0 | 2 |
| 390px / light | 6.80ms | 6.25% | 0 | 1 |
| 390px / dark | 6.70ms | 0.00% | 0 | 1 |

原始结果为 tmp/glass-review/performance.json，滚动 trace 为 desktop-scroll-trace.json。开发构建曾出现约 70–104ms 的 React 调度任务，实底对照同样存在；生产判断单独使用上述优化构建，不用开发模式数据声称生产达标。优化构建的上述增强场景均在约定的实验室预算内。

生产 p75 LCP/INP/CLS 没有真实用户采样，仍保留为设计目标。没有宣称真实应用或实体手机的 Web Vitals 已达标。

## 降级与遗留项

- 默认实底，通过标准/WebKit backdrop-filter 能力检测后增强；html 的 data-effects="solid" 可强制回退，不增加产品设置。强制颜色、增强对比、减少透明及打印保留文字、边界、焦点和任务功能。
- 尚未使用 Firefox、macOS/iOS Safari、实体 Android/iPhone 及辅助技术实机验收；200%/400% 浏览器缩放需另做实机确认，320 CSS px 重排已覆盖。
- 构建仍有大于 500kB 的分块提示；未引入新运行时依赖，未为视觉任务调整现有 Markdown/KaTeX 分包或业务加载策略。
- 真实账号下逐条业务内容的外观、生产网络性能及生产 p75 指标尚未验证；现有业务回归使用隔离数据库与模拟官网。
