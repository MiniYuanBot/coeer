# 社区功能与配置

## 列表与群组交流

反馈、群组、帖子、公告、活动、收藏、卡片、成就、商城与积分流水支持筛选和分页。
总数只在底部分页显示，使用与当前列表相同的筛选和可见性条件。
公开反馈只包含 `is_public=true` 的记录；本人的未公开反馈在“我提交的”查看。

群组人数只统计已批准成员，不包含待审核或已拒绝申请。
成员状态筛选仅作用于入群记录；审核或退群后重新查询会更新人数。
帖子详情中的顶层回复和各层同级回复按发布时间倒序，编辑不改变排序时间。
群成员可发布和查看回复，作者可编辑，作者及管理人员可删除；删除父回复会保留占位和后续对话。

帖子可点赞和收藏，“我的收藏”在 `/bookmarks`。失去私密群访问权限后，对应内容不再出现在收藏中。
正文编辑器支持基础 Markdown、行内公式 `$…$` 和独立公式 `$$…$$`，提供实时预览。
原始 HTML、危险链接和受信任 LaTeX 命令禁用，保存失败时保留草稿。

## 成就与活跃积分

管理员在成就管理中选择条件并填写目标数值，成就代码可留空自动生成，无需编写程序。
支持注册即得、累计登录天数、累计获得积分、累计提交反馈、创建或管理群组数、收集不同卡片数。
例如选择“累计登录天数”并填 `100`，或选择“累计获得积分”并填 `10000`。

注册即得在注册成功时发放，目标值固定为 `1`。登录天数依据每日活跃积分记录，按北京时间
统计不同日期，同日重复登录或访问只算一天，无需连续；已有记录会计入，未记录的历史日期不推算。
累计积分统计历史正数收入，兑换或抽卡消耗不会减少进度。
收藏家按拥有数量大于零的不同卡片种类计数；群组统计创建或以管理员身份管理的非驳回群组。

相关行为完成后检查解锁；访问成就页也会按已有业务数据为符合新规则的老用户补发，重复检查不重复发放。
原有初次发声、社群发起人和卡片收藏家的旧规则仍可使用。

## 成就图标与商品图片

两个管理页面均可选择本地 PNG、JPEG、GIF 或 WebP 图片，单张不超过 5 MB；保存前可预览、
移除或改填 HTTP(S) 图片地址。上传或保存失败时保留表单草稿。
图片在保存时上传，由服务端检查管理员权限、大小与文件格式，返回可用于图标和商品的图片地址。
成就卡片会展示已配置的图标，商城后台可编辑所有状态的商品，包括售罄与已下架商品。

图片内容保存在 `uploaded_images` 数据库表中，随数据库备份与恢复，不依赖发布目录。
替换、移除商品图片或删除上传者不会删除原始图片，以便已有引用继续访问。

| 行为 | 积分 | 每日次数上限 |
| --- | --- | --- |
| 访问社区 | +5 | 1 |
| 提交反馈 | +10 | 2 |
| 发帖 | +5 | 3 |
| 回复 | +2 | 5 |
| 活动签到 | +20 | 3 |

每日额度按北京时间零点重置。签到由主办方或管理员确认，同一活动只奖励一次。
奖励按用户串行核对限额，以稳定事件编号防重复；业务、奖励和成就写入同一事务。
个人中心可查看规则和完整积分流水。

## 通知与活动

`/notifications` 提供全部、未读、分页和已读管理，通知仅收件人可访问。
铃铛每 30 秒及页面重新获得焦点时刷新未读数。反馈状态、群组审核、入群审核和报名成功
会在对应业务事务中写入通知。

活动按时间显示即将开始、进行中或已结束，过期后关闭报名。
报名检查容量，取消后释放名额并允许重新报名；签到和名单受主办方与管理员权限限制。

## 密码与邮件

`/profile` 修改昵称和密码，`/forgot-password` 申请密码找回。
在环境文件或运行环境中配置：

```dotenv
APP_URL=https://coeer.example.com
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=coeer@example.com
SMTP_PASSWORD=your-mail-service-password
SMTP_FROM=COEER <coeer@example.com>
```

生产 `APP_URL` 使用 HTTPS。465 端口使用 TLS，其余端口强制 STARTTLS；
允许匿名的内部邮件中继可同时省略用户名和密码。未配置或发信失败时，页面提示不可用。

重置令牌放在 URL fragment，数据库只存摘要，有效期 30 分钟且只能使用一次。
同一邮箱每分钟最多申请一次、每小时五次，未知邮箱使用相同的响应和限流方式。
密码修改或重置后，旧会话和旧重置链接失效。

## 表结构升级

```sh
pnpm db:check:community
pnpm db:upgrade:community
```

增量升级补齐通知、密码找回、收藏、图片存储表与成就条件类型，可重复运行。已有部署应先执行升级，
再发布包含新条件与图片上传的版本。线上命令见
[deployment.md](deployment.md#数据库状态与升级)。
